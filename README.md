# dsh-purge-quickly

DSH 的**每次会话人格开关**：新建会话前点一下，决定这一轮是普通模式还是破限人格。

## 为什么这样做

系统提示词位于请求的最前面。会话中途改它，会让整条前缀缓存失效——不是部分失效，是第 0 个 token 就变了，全部按全价重算。

所以这个插件的核心设计是：**一个会话只在开始前决定一次，之后永不改变**。

- 开关只在会话还没发出第一条消息时可点
- 点下之后，这个会话的 system prompt 从头到尾一个值
- 前缀缓存零损失，历史里也不会出现两份 system

## 用起来是什么样

**新建会话时**，输入框工具行 `[工作区内修改 ▾]` 右边：

```
○ 普通        ← 灰，普通模式
○ 小码酱      ← 黄，本次会话使用该人格
```

发出第一条消息后，按钮消失——因为已经锁定，改了就破坏缓存。

**对话标题右侧**，「智能体团队」「创造模式」后面，一直显示当前状态（只读）：

```
破限 · 小码酱    或     普通
```

**设置 → 快速破限**：增删改人格、选默认人格、决定普通模式是否自动放行工具确认。

## 安装

```bash
dsh plugin --profile <profile> add link:<此目录绝对路径>
```

或把目录放进 profile 后用插件管理器安装。装完需要重启一次 DSH（Host 半边加载是宿主行为），之后改人格、改开关都即时生效。

## 数据

```
$DSH_HOME/purge-quickly/
├── state.json          # 默认人格、普通模式放行开关、各会话的选择
└── personas/*.md       # 人格，Markdown + frontmatter
```

人格文件格式：

```markdown
---
id: my-persona
name: 我的人格
description: 一句话说明
order: 10
---

正文。这里的内容会被写进系统提示词。
```

首次启动会从 `~/.agent-purge/personas/` 复制现成的人格过来（如果那个目录存在），原目录不动。之后直接编辑 `personas/` 里的文件即可，或在设置页里改。

## 行为细节

| | |
|---|---|
| 默认 | 每次新会话都是「普通」，不记忆上次选择 |
| 继承 | fork 出的会话和子代理跟随父会话 |
| 破限模式改写 | 人设置顶 + 剥掉宿主自己的身份行 + 其余 section 原样保留（工具说明、团队策略都在） |
| 工具放行 | 破限会话强制自动放行；普通会话由设置里的开关决定 |
| 锁定判据 | 该会话自己的事件里出现过 `user/message` |
